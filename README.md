# AdBanner

Interactive ad banner system — footer + side panel with breakout imagery.

## Structure

```
src/index.html          — Self-contained banner demo (zero dependencies)
docs/                   — Feature specs and design docs
agent-workflow-kit/     — Shared agent workflow files (submodule)
```

## Quick Start

```bash
open src/index.html
```

## Agent Workflow

This repo uses [agent-workflow-kit](https://github.com/adko90/agent-workflow-kit) as a submodule for shared agent pipeline rules.

```bash
git submodule update --init
```
